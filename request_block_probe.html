Request Block Probe CSP · CORS · NET

Sends each URL three ways and watches for CSP violation events, so it can tell "the request never left" apart from "it reached the server but the response was withheld from your code." Open the browser's Network tab alongside this for the ground truth.

environment

THROUGH & READABLE — request sent, response handed to your code (same-origin or CORS-permitted).
CORS-BLOCKED — request reached the server and it responded, but the browser refused to give the body to your code. The request did go through.
CSP-BLOCKED — a connect-src/default-src rule stopped the browser before it opened the connection. Nothing left the machine.
NO CONNECTION — both probes failed with no CSP event: DNS failure, refused, offline, or a block that emits no signal. Confirm with the Network tab.

To be 100% certain a request truly arrived somewhere, point a test at a URL you control (e.g. a free webhook.site address) and check whether the hit appears in its log.
